# Changelog

This changelog records changes verified in published GitHub releases. The initial release is documented from its published tag and tagged source because no earlier release is available for comparison.

## 1.0.0 - 2026-11-21

- Released a native Moodle teacher directory that discovers active teachers from direct course-level role assignments without duplicating teacher profile records.
- Added a searchable, paginated teacher listing, individual teacher profiles, visible-course listings and public curriculum fields, including graduation and LinkedIn information.
- Added administrator settings for teacher roles, directory visibility, guest access and Moodle messaging, together with teacher exclusions.
- Integrated capability and course visibility checks, Moodle privacy-provider support, and tests for teacher discovery and profile fields.

**Tagged source:** [1.0.0](https://github.com/EduardoKrausME/moodle-local_teacher/releases/tag/1.0.0)
